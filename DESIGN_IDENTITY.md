# Cartographic identity

## Mechanism signature

The contract changes a shared semantic set. A sounding can create an island, deepen exactly one existing island, or be recorded as a duplicate without changing the map.

## Product metaphor

A field cartographer sounding depth around an archipelago. Risk clusters are landforms, additional mechanisms add contours, and redundant notes remain echoes in the observation log.

## Interaction grammar

The map is the product. One field-note sheet sits below an edge-to-edge canvas. The user never navigates a dashboard or repeated argument boxes; the visible composition changes after every finalized sounding.

## Voice and documentation

Patient, observational prose with field-note vocabulary and longer sentence rhythm. The README reads like a survey folio rather than an operator manual.

## Evidence story

The live record must show two semantically distinct notes raising two islands, a related note adding depth without a third island, and a normalized replay leaving all counts unchanged.
